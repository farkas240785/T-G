# Переработанный AI-консультант

## 🎯 Цель переработки

Создать AI-консультанта, диалог с которым **неотличим от живого консультанта**.

---

## ✨ Ключевые улучшения

### 1. **Естественный язык общения**

**Было:**
```
Здравствуйте! Я — AI-консультант мануфактуры «Тигель & Горн».
Помогу подобрать фурнитуру для вашего проекта ОКН...
```

**Стало:**
```
Здравствуйте! Меня зовут Алексей, я технолог мануфактуры «Тигель и Горн».
Работаю с реставрационной фурнитурой уже 12 лет. 
Расскажите, пожалуйста, над каким проектом вы сейчас работаете?
```

**Что изменилось:**
- ✅ Персонализация (имя, опыт работы)
- ✅ Естественные приветствия с вариативностью
- ✅ Активное слушание и уточняющие вопросы
- ✅ Профессиональный, но дружелюбный тон

---

### 2. **Контекстная память диалога**

Система запоминает:
- Тип клиента (архитектор, снабженец, реставратор)
- Название объекта
- Исторический период
- Тип фурнитуры
- Количество изделий
- Сроки
- Контактную информацию

**Пример диалога:**
```
Клиент: Мне нужна помощь с подбором
AI: Отлично! Чтобы я мог предложить вам наиболее подходящие решения, 
    расскажите немного о вашем объекте. Это храм, усадьба, музей 
    или другое здание?

Клиент: Это усадьба в стиле классицизм
AI: Понимаю вас. Классикизм — прекрасный период! У нас есть опыт 
    работы с такими объектами. Теперь давайте уточним...
```

---

### 3. **Адаптивный стиль общения**

AI определяет тип клиента по контексту и адаптирует стиль:

**Для архитектора/ГИП:**
- Акцент на технические детали
- Упоминание ГОСТов и нормативов
- Обсуждение исторической достоверности

**Для снабженца:**
- Фокус на сроках и бюджете
- Поэтапная оплата
- Документооборот

**Для реставратора:**
- Профессиональная терминология
- Обсуждение методов патинирования
- Согласование с КГИОП

### 5. **Профессиональная экспертность**

AI демонстрирует глубокие знания:

**Пример ответа о материалах:**
```
Мы используем только исторически обоснованные сплавы — это 
принципиальная позиция.

Основные материалы:
• Латунь Л63 (ГОСТ 17711-93) — основной сплав для литья, 
  имеет историческую преемственность
• ЛС59-1 — свинцовая латунь для сложных форм
• Сталь Ст3 — для кованых элементов
• Чугун ЧХН — для чугунного литья

Важно: мы принципиально не используем ЦАМ (цинковые сплавы) — 
они не соответствуют нормативам КГИОП и не имеют исторической 
преемственности. Это касается только объектов культурного наследия.

На каждую партию мы выдаём паспорт сплава с результатами 
спектрометрии. Это обязательное требование для согласования.

Для вашего проекта какой сплав рассматриваете?
```

### 6. **Плавные переходы между темами**

**Было:**
```
Клиент: Какие сроки?
AI: Минимальный срок — 30 дней.
```

**Стало:**
```
Клиент: Какие сроки?
AI: Понимаю, сроки и бюджет — это всегда важно.

По срокам: минимальный срок изготовления — 30 дней с момента 
согласования. Но обычно мы закладываем 45-60 дней, чтобы учесть 
все этапы: исследование, производство, патинирование, ОТК.

По стоимости: она зависит от нескольких факторов — типа изделия, 
сплава, количества, сложности патинирования. Например, ручка-скоба 
из латуни Л63 с горячей патиной будет стоить от 12 500 рублей 
за штуку.

Чтобы я мог дать вам более точную оценку, расскажите:
• Какой тип фурнитуры вам нужен?
• Примерное количество?
• Есть ли исторические прототипы или архивные материалы?
```

## 🧠 Техническая реализация

### Система контекста:
```typescript
type ConversationContext = {
  clientType?: 'architect' | 'customer' | 'restorer' | 'unknown';
  projectName?: string;
  objectType?: string;
  epoch?: string;
  quantity?: string;
  deadline?: string;
  budget?: string;
  contactInfo?: string;
  currentTopic?: string;
  lastUserMessage?: string;
  messageCount: number;
};
```

### Определение типа клиента:
```typescript
function detectClientType(message: string): 'architect' | 'customer' | 'restorer' | 'unknown' {
  const lower = message.toLowerCase();
  if (lower.includes('гип') || lower.includes('архитектор') || lower.includes('проект')) {
    return 'architect';
  }
  if (lower.includes('снабжение') || lower.includes('закупк') || lower.includes('смет')) {
    return 'customer';
  }
  if (lower.includes('реставрац') || lower.includes('окн') || lower.includes('кгип')) {
    return 'restorer';
  }
  return 'unknown';
}
```

### Генерация естественных ответов:
```typescript
function generateResponse(input: string): React.ReactNode {
  const q = input.toLowerCase();
  context.messageCount++;
  context.lastUserMessage = input;

  // Определяем тип клиента при первом сообщении
  if (context.messageCount === 1) {
    context.clientType = detectClientType(input);
  }

  // Приветствие и начало диалога
  if (context.messageCount === 1 && (q.includes('здравств') || q.includes('привет'))) {
    const greeting = greetings[Math.floor(Math.random() * greetings.length)];
    return (
      <>
        <p>{greeting}</p>
        <p className="mt-2">Меня зовут Алексей, я технолог мануфактуры «Тигель и Горн». 
        Работаю с реставрационной фурнитурой уже 12 лет.</p>
        <p className="mt-2">Расскажите, пожалуйста, над каким проектом вы сейчас работаете? 
        Это поможет мне лучше понять ваши потребности.</p>
      </>
    );
  }
  
  // ... остальная логика
}
```
